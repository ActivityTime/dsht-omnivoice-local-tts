## 五河士道 Shido（00）——主角
> 语气特征：温和坚定的少年音。**注意：士道语料多为第一人称旁白叙述**（视觉小说式「俺は…」），测旁白音色正好，当对话台词用会缺对象感。

1. **[平静·日常对话]** 「期末試験が終わった夏休み前、俺やトウカたちは修学旅行に向かうことになった。」
   - 中译：期末考试结束、暑假之前的这段时间，我们和十香他们决定要去修学旅行了。
   - 场景：剧情旁白——修学旅行篇开幕
   - 素材：`ja_Shido_0001_平静_日常对话.wav`（6.6s）
2. **[坚定·呼唤对方]** 「約束通り…お前を…助けに来た!」
   - 中译：如约……前来……救你了！
   - 场景：冲破阻碍赶到同伴身边的决战宣言，气息急促但斩钉截铁
   - 素材：`ja_Shido_0014_坚定_呼唤对方.wav`（6.2s）
3. **[坚定·呼唤对方]** 「マリア!マリナ!このまま終わるなんて絶対にダメだ!」（※ 无误）
   - 中译：鞠亚！鞠奈！怎么能就这样结束，绝对不行！
   - 场景：《凛绪轮回》终盘，同时向姐妹俩喊话的挽回场景
   - 素材：`ja_Shido_0015_坚定_呼唤对方.wav`（6.2s）
4. **[恋慕·恋爱情话]** 「マリアの提案で、俺はマリアとデートすることになった。」
   - 中译：因为鞠亚的提议，我和她开始了约会。
   - 中译注：叙述句但内容是约会，温柔中藏着雀跃
   - 素材：`ja_Shido_0016_恋慕_恋爱情话.wav`（4.5s）
5. **[惊讶·惊讶愕然]** 「でも…そんな…まさか…あいつが…」
   - 中译：可是……怎么会……难不成……那家伙他……

   - 素材：`ja_Shido_0018_惊讶_惊讶愕然.wav`（6.0s）
