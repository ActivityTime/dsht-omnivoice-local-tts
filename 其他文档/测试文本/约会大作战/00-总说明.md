## ⚠️ 逐字稿质量警告（做克隆前必读）

素材库的 txt 逐字稿全部由 ASR 转写，**存在系统性的同音字错误**，集中在角色名和口癖句尾。
直接拿错误逐字稿做克隆参考会导致音画对齐漂移（OmniVoice 克隆依赖逐字稿与音频逐字对齐）。
下表是本次整理全部 522 条中实际出现的错误模式，**使用素材前建议先按此表校对**：

| ASR 错转（出现形式） | 正确写法 | 说明 |
|---|---|---|
| 指導 / 五日 / 志堂 / シロー / シード / シド / いつか / いつかくん | **シドウ**（士道） | 最高频错误，多种变体并存 |
| トビーチ / トビチ / トビイチ | **オリガミ**（鸢一折纸） | |
| 十日 / 十日ちゃん / トウカチャー / トーカ | **トウカ**（夜刀神十香） | |
| 吉野 / ヨシナン | **ヨシノ**（四糸乃） | 另有「ヨシノン」= 四糸奈（手偶），二者勿混 |
| くるみん / クルミン / クルミ | **コトリ**（五河琴里） | 琴里被众人昵称「クルミン」不算错，但 ASR 会把普通对话里的琴里也转成它 |
| ミクタ / ミクタン / ミクトン | **ミク**（诱宵美九）/ **ミオ**（崇宫澪） | 按说话人区分 |
| いつか司令 / 五日指導 | **シドウ**+「司令」（琴里黑缎带模式） | 复合错误 |
| 我ら**病** | 我ら + 句尾口癖（〜だし / 〜であるし） | 耶俱矢口癖被识别成汉字「病」 |
| 〜しやがります / 〜で嫌がります | 〜ですよ / 〜ですか | 真那口癖被错误扩展 |
| 失笑 / 軽眼 / 珍味 / 戦亡 / 敬願 / 皇帝 / 趣向 | 夕弦的前置评价词（発言 / 軽嘆 / 尋問 / 戦慄 / 慶賀 / 裁定 / 趣向…） | 夕弦语料整条都有这类错误，建议整条校对 |

另外：士道的语料大量为**第一人称旁白叙述**（视觉小说式），不是台词——用来测旁白音色正好，但别当对话台词用。
个别条目（如 Tohka_0003）ASR 整句识别成了无关的演歌歌词，属识别事故，不建议使用。

## 用法建议

1. **克隆参考音频**：素材库每条即 48 kHz / 3–10 s / 单情绪 / 无 BGM 的游戏语音，已是现成的 `spk_audio_prompt`。优选 tier 1（时长 3–10 s）条目；逐字稿先按上面的对照表校对再喂。
2. **单角色情绪扫描**：一个角色固定文本、换不同情绪的参考音频（如狂三 0004 得意 vs 0020 愤怒），听情绪是否带得出来。
3. **口癖还原测试**：专测口癖角色——狂三「ですわ」、耶俱矢「我ら」、真那「ですよ」、夕弦前置词、Rio「パパ」——口癖是角色辨识度最高的特征，也是 TTS 最容易崩的地方。
4. **旁白/长文本测试**：士道的旁白条 + Ruler 的 13.9 s / 18.3 s 长句，测长文本连贯与气口。
5. **跨语种口音测试**：把同一角色的台词用 zh / en 合成，听日语音色说外语的违和感（OmniVoice 646 语言表里 `ja` 显式指定）。
6. **场景演绎（跑团）**：`场景描述示例.md` 的场景模板 + 各角色台词，可直接拼成小剧场剧本。
