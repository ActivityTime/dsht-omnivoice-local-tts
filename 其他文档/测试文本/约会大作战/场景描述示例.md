# 约会大作战 · 场景描述示例

按**剧情场景**聚合的台词索引 + 可直接用于跑团 / 剧情演绎 / 小剧场拼接的场景描述模板。
台词详情（原文+翻译）见 `角色语音示例.md`，此处只做索引与场景化包装。

## 怎么用

1. **选场景**：从下面七个场景挑一个氛围。
2. **挑角色台词**：按索引表选 2–4 个角色，每人 1–2 句，情绪尽量拉开（平静 × 激动 × 暴走）。
3. **喂 TTS**：每句单独合成（克隆音色 = 角色，情绪 = 参考音频情绪；或 IndexTTS `emo_vector` 按 `00-总说明.md` 映射表设置）。
4. **拼装**：按场景模板的节奏拼接，加转场描述即成小剧场。

## 场景一 · 日常校园（闲适 · 安定）

**氛围模板**：
> 清晨的来禅高中，走廊里是迟到的生徒和敷衍的寒暄。没有空间震警报，没有〈公主〉的鏖杀，只有五河士道被日常追赶的、略显狼狈的早晨。琴里在玄关打着哈欠交代便当，亚衣麻衣美衣三人组已经在教室前排开盘今天的八卦。这是暴风雨前，珍贵的平静。

**适用情绪**：calm（平静）/ gentle（温柔）/ smug（得意）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 五河琴里 | 白缎带模式对哥哥的娇嗔（等 40 秒的饭） | `ja_Kotori_0007` |
| 冈峰珠惠 | 门边抓迟到的元气寒暄 | `ja_Tamae_0011` |
| 冈峰美纪惠 | 兴奋安利蛋糕店 | `ja_Mikie_0001` |
| 或守鞠亚 | 礼貌而疏离的得体说明 | `ja_Maria_0001` |
| 日下部燎子 | 边吐槽边拉评理的豪爽 | `ja_Kusakabe_0001` |
| 八舞夕弦 | 冷静分析商业机制 | `ja_Yuzuru_0003` |

**演绎提示**：语速放慢、音量压低；琴里 vs 珠惠的「教师/妹妹双重视线」是天然喜剧对位。

## 场景二 · 战斗与决意（炽烈 · 保护）

**氛围模板**：
> 空间震警报划破天际，〈公主〉的鏖杀天使在街道上铺开光之轨迹。AST 的显现装置装置启动，折纸的制服在硝烟中翻飞。士道冲破烟幕——「约好的，我来救你了。」这一刻不需要修辞，只有斩钉截铁的音节砸向对手。

**适用情绪**：shout（呼喊）/ determined（坚定）/ anger（愤怒）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 五河士道 | 决战宣言「如约……前来救你了！」 | `ja_Shido_0014` |
| 夜刀神十香 | 「士道由我来保护！到我身后来！」 | `ja_Tohka_0002` |
| 八舞耶俱矢 | 战斗后的主权宣告 | `ja_Kaguya_0019` |
| 崇宫真那 | Search & Destroy 式亢奋咆哮 | `ja_Mana_0003` |
| 时崎狂三 | 愤怒低语（优雅声线里的刺） | `ja_Kurumi_0020` |
| 藤袴美衣 | 中二式热血宣告 | `ja_Mii_0018` |

**演绎提示**：全员音量拉满、语速加快；士道的「坚定」与十香的「呼喊」形成「低音承诺 × 高音守护」的经典双声道。

## 场景三 · 恋爱与告白（甜腻 · 危险）

**氛围模板**：
> 泳装卖场的更衣室门口，或者傍晚无人的教室。狂三的「当然会为我选合适的泳装对吧？」尾音上挑，折纸用零波澜的声线宣读正宫宣言，凛祢一句「这一切我都会回应你」轻轻落下——恋爱场景在约战里从来不是粉色的，是带刀片的糖。

**适用情绪**：love（恋慕）/ shy（羞涩）/ smug（得意）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 时崎狂三 | 泳装挑选的甜蜜胁迫 | `ja_Kurumi_0004` |
| 时崎狂三 | 危险发言配羞涩语气 | `ja_Kurumi_0005` |
| 时崎狂三 | 「想了解恋人的秘密是正当欲望」 | `ja_Kurumi_0011` |
| 鸢一折纸 | 面无表情的正宫宣告 | `ja_Origami_0010` |
| 园神凛祢 | 「这一切我都会回应你」 | `ja_Rinne_0002` |

**演绎提示**：狂三（甜）与折纸（淡）同框是约战最大反差——同一句恋爱台词，两种极端演绎，测 TTS 情绪控制必拼。

## 场景四 · 吐槽与搞笑（喧闹 · 失控）

## 场景五 · 悲伤与离别（低回 · 挽留）

**氛围模板**：
> 雨，或者即将消失的光之粒子。凛祢的身体一点点变成光，四糸乃低着头说不出一句完整的话，狂三收起笑意的「那也只是个可爱的女孩子罢了」——约战的悲伤从不用哭喊完成，用未说完的句子完成。

**适用情绪**：sad（悲伤）/ cry（哭泣）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 四糸乃 | 欲言又止的信赖 | `ja_Yoshino_0006` |
| 四糸乃 | 「还……有点……刺痛……」 | `ja_Yoshino_0012` |
| 时崎狂三 | 悲伤中的自我否认 | `ja_Kurumi_0030` |
| 山吹亚衣 | 「趁现在开始找别人也可以哦」 | `ja_Ai_0006` |
| 五河士道 | 惊讶到语无伦次 | `ja_Shido_0018` |
| 村雨令音 | 疲惫时的安抚 | `ja_Reine_0001` |

**演绎提示**：弱声线 + 停顿拉长；四糸乃的「す…少し…だけ…」（气声断句）是本场景的试金石。

## 场景六 · 亲密与温柔（静谧 · 治愈）

**氛围模板**：
> 深夜的士道家厨房，或者清晨神社的台阶。令音懒洋洋地分析形势，四糸乃低着头说「现在的士道先生就好了」，凛祢系上围裙说晚饭我来做——战斗间隙的治愈回，是角色音色最柔软的一面。

**适用情绪**：gentle（温柔）/ calm（暖色变体）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 四糸乃 | 「士道先生保持现在这样就好」 | `ja_Yoshino_0015` |
| 园神凛祢 | 「士道的晚饭我来做」 | `ja_Rinne_0005` |
| 鸢一折纸 | 「就算是那样的士道也欢迎之至」 | `ja_Origami_0017` |
| 或守鞠亚 | 温柔的制止（对凛绪） | `ja_Maria_0009` |
| 村雨令音 | 低沉可靠的安抚 | `ja_Reine_0001` |
| 四糸奈 | 意外会看气氛的圆场 | `ja_Yoshinon_0020` |

**演绎提示**：全场景最小音量、最慢语速；「温柔」情绪是 OmniVoice 无情绪轴架构下最依赖参考音频的维度，建议直接用 gentle 标签素材做参考。

## 场景七 · 旁白与解说（疏离 · 叙事）

**氛围模板**：
> 画面暗下，叙述者的声音浮起。士道的第一人称旁白推进剧情，夕弦用解说词给喧闹打分，令音在弗拉克西纳斯的屏幕光里梳理情报——这是角色的「非角色状态」，也是长文本连贯性的最佳考场。

**适用情绪**：narration / calm（零情绪）

| 角色 | 台词摘要 | 素材编号 |
|---|---|---|
| 五河士道 | 修学旅行篇开幕旁白 | `ja_Shido_0001` |
| 五河士道 | 「救下了第二位精灵」 | `ja_Shido_0004` |
| 八舞夕弦 | 解说式评价 | `ja_Yuzuru_0013` |
| 村雨令音 | 系统重启的技术报告 | `ja_Reine_0002` |
| 支配者 | 神性哲学质问（13.9 s 长句） | `ja_Ruler_0001` |
| 支配者 | 「那就来杀了我吧」（18.3 s 长句） | `ja_Ruler_0002` |

**演绎提示**：Ruler 的两条是全库最长（13.9 s / 18.3 s），专测**长句气口与语义重音分配**——合成后重点听句中停顿是否自然。

## 附 · 小剧场拼接示例（三分钟）

> 用以上素材可以快速拼一个「日常 → 突变 → 收束」的迷你回：

1. **[日常校园]** 琴里 `ja_Kotori_0007`（白缎带娇嗔）→ 珠惠 `ja_Tamae_0011`（元气寒暄）
2. **[突变]** 澪 `ja_Mio_0013`（兴奋低语「该不会是约会吧！？」）→ 十香 `ja_Tohka_0002`（战斗守护宣言）
3. **[收束]** 士道 `ja_Shido_0014`（决战宣言）→ 四糸乃 `ja_Yoshino_0015`（温柔安抚）→ Ruler `ja_Ruler_0002`（神性收尾，长句）

> 六个人、三种情绪档位、一个完整弧线——这就是本素材库做场景回归测试的最小完备集。
