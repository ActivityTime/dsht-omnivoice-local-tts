# 动漫 / 游戏台词测试文本 · 总说明

本目录收录**面向「动漫角色 TTS」测试**的台词范例，按「典型场景 / 情绪」组织，尽量给出 **中 / 日 / 英三语对照**，方便在同一情绪下跨引擎（GPT-SoVITS / IndexTTS-2.5）与跨语种（zh / ja / en）对比测试。

## 为什么单独成库

基础语料（绕口令、pangram、音素平衡句）只能测"发音准不准"。
角色 TTS 真正要测的是：**同一角色用不同情绪 / 不同场景说话时，语气、节奏、断句是否自然**——这只能用"角色本就会说的台词"来测。所以这里全部是真实作品里的名台词。

## 场景 / 情绪分类

| 场景文件 | 覆盖情绪（IndexTTS `emo_vector` 维度） |
|---|---|
| 战斗与决心 | angry / calm |
| 日常与温柔 | calm / happy |
| 悲伤与离别 | sad / melancholic |
| 愤怒与对峙 | angry / disgusted |
| 惊喜与喜悦 | happy / surprised |
| 搞笑与吐槽 | happy |
| 悬念与低语 | afraid / melancholic |

## 情绪向量速查（IndexTTS-2.5）

`emo_vector` 顺序固定：**[happy, angry, sad, afraid, disgusted, melancholic, surprised, calm]**，每维 0.0–1.0。
例：`[0,0.8,0,0,0,0,0,0]` = 愤怒 0.8；`[0,0,0,0,0,0.6,0,0.2]` = 忧郁偏沉静。

> GPT-SoVITS / ModelScope 合集走的是"换参考音频"路线，情绪标签对齐这 7 类（中立/开心/生气/难过/恐惧/吃惊/厌恶），用法见 `../00-总说明与来源.md`。

## 用法建议

1. **单角色三语种回归**：挑 1 个角色，对每条台词分别用 zh / ja / en 跑，听音色一致性 + 跨语种口音。
2. **单情绪强度扫描**：同一句"愤怒"台词，把 `emo_vector` 第 2 维从 0.2 扫到 1.0，挑最自然的一档。
3. **音色稳定性压测**：同一条参考音频连跑 20 句，听是否有"窜音色"（OmniVoice 社区反馈过的女声窜男声问题）。
4. **日语纯文本**：见 `日语原文精选.md`，已去标点注音、可直接喂日语 TTS。
