# 中文 · 标准测试与音素平衡

用于确认服务通、音色加载成功，以及覆盖声母/韵母/声调/数字/标点。

## 一、快速冒烟测试（短句）

1. 你好，我是测试语音。
2. 今天天气真好。
3. 这是一段话转语音的测试。
4. 请听这一段中文发音是否清晰。

## 二、普通话标准测试句（新闻播报体，涵盖常用声韵母）

1. 北京是中国的首都，拥有悠久的历史和灿烂的文化。
2. 人工智能技术正在快速发展，深刻地改变着我们的生活。
3. 春风拂过辽阔的草原，带来一阵清新而温暖的气息。
4. 科学家们在实验室里夜以继日地探索未知的奥秘。
5. 这座城市的高楼大厦在夕阳下闪烁着金色的光芒。
6. 我们要保护好环境，让天空更蓝、河水更清。
7. 经济发展与生态保护应当协调推进，不可偏废。
8. 无论遇到多大的困难，只要坚持就一定能克服。

## 三、数字 / 日期 / 标点 专项

1. 今年的国内生产总值增长了百分之五点二。
2. 会议召开时间是二〇二六年十月二十二日上午九点三十分。
3. 电话号码是一三八，零一二三，四五六七。
4. 价格区间在三百元到五百元之间，含运费。
5. 请问：去火车站该怎么走？——一直往前，第二个路口左转！
6. 他买了苹果、香蕉、橘子，还有一盒巧克力（进口的）。
7. 温度降至零下十二摄氏度；风力达到六级，请注意保暖。

## 四、四声与易混音专项

1. 妈 mā / 麻 má / 马 mǎ / 骂 mà（四声对比）
2. 四是四，十是十；十四是十四，四十是四十。（s/sh）
3. 牛郎年年恋刘娘，刘娘年年念牛郎。（n/l）
4. 红凤凰，粉凤凰，红粉凤凰，花凤凰。（f/h）
5. 蓝衣布履，绿衣布履，蓝绿布履分不清。（l/n）

> 用法：第 2、3、4 项同时可当作"滑舌"训练素材，但更系统的绕口令见 `03-绕口令-滑舌.md`。
