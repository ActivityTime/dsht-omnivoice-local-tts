# 中文 · 日常对话

适合做**克隆参考音频**的口语文本：自然、无书面腔、情绪单一，录制 3–10 秒即可。

## 一、轻松闲聊

1. 诶，你今天怎么来得这么早？
2. 我刚泡了杯茶，要不要一起坐会儿？
3. 周末有什么安排吗？要不要出去转转。
4. 这家店的东西还真不错，下次还来。
5. 外面有点凉，记得多穿一件外套。

## 二、叙述与讲述

1. 我跟你说件有意思的事，昨天在路上碰见个老同学。
2. 那时候我们还小，总喜欢跑到河边去抓蝌蚪。
3. 这本书我看了三遍，每一遍都有新的体会。
4. 他这个人吧，嘴上不说，心里其实都记着呢。
5. 故事要从很久以前讲起，那是一个安静的小镇。

## 三、角色台词感（偏二次元/陪伴向）

1. 喂，别走那么快啊，等等我啦！
2. 哼，才不是担心你呢，只是顺路而已。
3. 交给我吧，这点小事难不倒我的。
4. 谢谢你一直陪着我，真的……很重要。
5. 不管发生什么，我都会站在你这边的。

> 用法：第 1、2 部分偏中性语气，适合做干净音色参考；第 3 部分语气更鲜明，可作为带轻微情绪的参考素材（注意：OmniVoice/IndexTTS 克隆以音色为主，情绪主要来自文本或 `emo_*` 参数，参考音频的情绪仅作弱引导）。
