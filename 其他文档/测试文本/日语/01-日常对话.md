# 日本語 · 日常会話

クローン参照音声（自然な口語、3–10 秒録音）に適したテキスト。

## 気軽な雑談
1. おはよう、今日はずいぶん早いね。
2. お茶淹れたんだけど、少し一緒に休まない？
3. 週末は何か予定ある？ちょっと出かけない？
4. ここなかなかいいね、また来よう。
5. 外が少し冷えてきたから、上着持っていったほうがいいよ。

## 語り・ナレーション
1. 面白い話があるんだけど、昨日道で昔の友達に会ったの。
2. 小さい頃はよく川へ行って、おたまじゃくしを捕まえてたっけ。
3. この本はもう三回読んだけど、読むたびに新しい発見がある。
4. あの人は口には出さないけど、全部ちゃんと覚えてるんだよね。
5. 話はずっと昔、静かな小さな町から始まる。

## キャラ風（アニメ・添い寝向け）
1. おい、そんなに早く歩かないでよ、待ってってば！
2. ふん、別にあんたのこと心配なんかしてないんだからね、たまたま通りかかっただけ。
3. 任せておいて、こんなのわたしにゃ朝飯前だから。
4. いつもそばにいてくれて、本当に…ありがとう。
5. 何があっても、わたしはあんたの味方だからね。
