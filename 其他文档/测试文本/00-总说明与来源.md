## 各库的来源（均为业界常用公开测试集）

- **Harvard Sentences（H1–H9）**：IEEE 1965 修订版音素平衡句，电信/语音合成标准测试语料，覆盖英语全部音素且频率贴近自然语。
- **Stella Passage**：George Mason 语音口音档案用购物清单式音素覆盖文本，约 2800+ 说话人录制过，自然口语、约 20 秒。
- **Rainbow Passage**：Grant Fairbanks 1960《Voice and Articulation Drillbook》，几乎涵盖美式英语全部音素的叙事文本，SLP/方言学标准样本。
- **The quick brown fox / Pack my box…**：经典字母全包含 pangram（仅测字母覆盖，不测音素，作快速冒烟测试用）。
- **TTS-Multilingual-Test-Set（MiniMaxAI）**：24 语种各 100 句 + 男女说话人克隆素材，评估多语种零样本克隆（CC-BY-SA-4.0）。
- **OpenVoiceOS/tts-test-sentence**：彩虹句（"雨后彩虹"）跨语种翻译，快速 sanity-check 多语种发声是否可懂。
- **中文普通话测试句 / 诗歌 / 绕口令**：中文 TTS 通用自测素材（新闻播报体、古诗韵律、四是四十是十等滑舌）。
- **日语早口言葉（隣の客はよく柿食う客だ 等）**：日语发音清晰度/滑舌经典，测清音、促音、拗音、拨音。
- **约会大作战全角色游戏语音**（`约会大作战/`）：HF `hzrr/audio7z`（《凛绪轮回》HD 解包语音）筛选 26 角色 522 条，每条带情绪/场景标签，与克隆素材库 `prompt/datealive/ja/` 一一对应；逐字稿为 Whisper ASR 转写，**含系统性同音字错误，详见该库总说明的对照表**。

## 怎么用

1. **挑克隆参考音频**：从「日常对话」各文件挑 3–10 秒、无背景音、情绪单一、朗读者本人本色的句子录制 → 当 `spk_audio_prompt`（IndexTTS-2.5）或克隆素材（OmniVoice）。
2. **快速冒烟测试**：用 pangram / 短标准句，确认服务通、音色加载成功。
3. **音素覆盖测试**：用 Harvard / Stella / 普通话测试句，听清辅音、元音、声调是否清楚。
4. **情绪测试**：用「情绪表达」+「跨语言情绪对照」文件，配合参考音频或 `emo_vector` 验证情绪是否带得出来。

## 情绪维度 → 引擎参数映射（关键）

GPT-SoVITS（ModelScope 合集）参考音频按 **7 类** 标注：中立 / 开心 / 生气 / 难过 / 恐惧 / 吃惊 / 厌恶。
IndexTTS-2.5 的 `emo_vector` 是 **8 维**，顺序固定：

| 情绪 | IndexTTS emo_vector 位 | 值示例 |
|---|---|---|
| 开心 happy | 第 1 位 | `[0.8,0,0,0,0,0,0,0]` |
| 生气 angry | 第 2 位 | `[0,0.8,0,0,0,0,0,0]` |
| 难过 sad | 第 3 位 | `[0,0,0.8,0,0,0,0,0]` |
| 恐惧 afraid | 第 4 位 | `[0,0,0,0.8,0,0,0,0]` |
| 厌恶 disgusted | 第 5 位 | `[0,0,0,0,0.8,0,0,0]` |
| 忧郁 melancholic | 第 6 位 | `[0,0,0,0,0,0.8,0,0]`（对应"难过"的补充维度）|
| 吃惊 surprised | 第 7 位 | `[0,0,0,0,0,0,0.8,0]` |
| 平静 calm | 第 8 位 | `[0,0,0,0,0,0,0,0.8]`（对应"中立"）|

> 提示：`emo_alpha`（0.0–1.0）控制音色与情绪的混合比，默认 1.0；拉太高会偏离本人音色，建议从中等起步。
> GPT-SoVITS 无结构化情绪参数，只能换带情绪的参考音频；OmniVoice 无情绪轴，情绪需靠素材本身携带。
