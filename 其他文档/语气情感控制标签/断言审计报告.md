## 一、被我编造的两条：组合与强度

### 1.1 ❌「官方 13 符号无法组合」——**假的**

**我当时的依据**：源码正则里 13 个标签是并列的，我凭直觉以为"一次只能一个"。

**实际源码**（`omnivoice/models/omnivoice.py`，`_tokenize_with_nonverbal_tags`）：

```python
for m in _NONVERBAL_PATTERN.finditer(text):   # ← finditer：逐个匹配，可重复
    ...
    tag_ids = tokenizer(m.group(), add_special_tokens=False).input_ids
    parts.append(tag_ids)
```

`finditer` 遍历所有匹配，**每个标签独立分词、独立拼接**——源码里**没有任何"只能一个"的约束**。

**实测**（官方基座，英文同一句）：

| 用例 | 时长 | RMS | 频谱质心 | 动态范围 |
|---|---:|---:|---:|---:|
| 无标签 | 3.68 s | 0.0847 | 3045.6 | 3.67 |
| `[laughter]` | 4.36 s | 0.0988 | 1594.3 | 4.59 |
| `[laughter] [sigh]` | **4.72 s** | 0.0850 | 2427.6 | 3.23 |
| `[laughter] [sigh] [question-en]` | **5.56 s** | 0.0658 | 2723.9 | 3.90 |
| 标签插在句中 | 3.96 s | 0.0706 | 3919.5 | 2.96 |

→ 时长**随标签数递增**（3.68 → 4.36 → 4.72 → 5.56 s），说明**每个标签都独立生效**，可以叠加。
→ 标签**也可以放在句子中间**，不限于句首。

### 1.2 ❌「无法调强度」——**也是假的**

**实测**（同一句、同一标签，只改重复次数）：

| 用例 | 时长 | RMS | 频谱质心 | 动态范围 |
|---|---:|---:|---:|---:|
| `[laughter]` ×1 | 4.36 s | 0.0988 | 1594.3 | 4.59 |
| `[laughter]` ×2 | 4.92 s | **0.1262** | 3006.1 | 2.92 |
| `[laughter]` ×3 | 5.64 s | 0.0863 | 2489.7 | 3.76 |

→ 三次产出**互不相同**（RMS 0.099 → 0.126 → 0.086），
说明**重复标签会改变音频**——重复本身构成了一种「强度」控制手段
（尽管**没有独立的强度参数**，效果也**非线性**、不稳定）。

> ⚠️ **注意**：重复的效果**不可控**（×2 反而比 ×3 更响），
> 所以「可用重复调强度」是**事实描述**，不是「推荐用法」。

## 二、被我表述误导的一条：拟声 vs 情绪

**我当时写的**：「命名带 `-en/-ah/-oh` 等后缀说明它们是**特定语种的声学拟声**，
不是语义化的情绪词；`[dissatisfaction-hnn]` 是唯一带情绪语义的」。

**问题**：后半句是我拿「拟声 ≠ 情绪」这个先验套上去的，**没有实证**。
而且前半句用「说明」二字，把**命名推断**说成了**事实**。

**实际情况**：
- 13 个标签在 tokenize 层面**完全同等**——没有"拟声类"与"情绪类"的机制差异。
- `[laughter]`（笑）、`[sigh]`（叹气）本身就**是**情绪/行为的直接表达，
  说它们"不是语义化情绪词"是把话说窄了。
- 唯一能确证的是它们的**形式**：都是**单个拟声/发声**，**没有可调的强度或程度参数**。
- 跨语言实测（见 §三）显示 `[question-en]`、`[question-ah]` 这类**语种特定的拟声
  在日文语境下并不按语种切换**——这才是"它们是拟声而非情绪"的可观测证据，
  但我当时**没测**。

**已改为**：「13 个标签都是**单个拟声/发声**，形式上无强度参数；
其中带 `-en/-ah/-oh/-ei/-yi` 后缀的是**特定语种的拟声写法**，
换语种使用时该拟声未必对应当地语言的习惯表达。」

## 三、我给得太悲观的结论：日文情绪「完全未验证」

**我当时写的**：「情绪 / 韵律微调的训练语料都是英文或哈萨克语——
对约战素材的**日文情绪完全未验证**，日文演出仍应走克隆路线。」

**诚实之处**：我当时**确实没测**，说"未验证"不算编造。

**问题**：基于"训练语料是英文"直接推出"日文不行"，
这个推理**跳了一步**——微调模型完全可能把情绪语义**迁移**到其他语言
（很多英文训练的多语种模型都这样）。我没测就下了悲观结论。

### 实测结果（`emotion-en` 微调，同一标签 × 两种语言，各自对自己的无标签基线）

| 标签 | 指标 | 英文 Δ% | 日文 Δ% | 方向一致? |
|---|---|---:|---:|:---:|
| **`[whisper]`** | RMS | −48.0% | **−57.1%** | ✅ |
| | 频谱质心 | +39.9% | **+73.1%** | ✅ |
| | 动态范围 | +57.4% | **+106.6%** | ✅ |
| | 时长 | +16.3% | +17.4% | ✅ |
| **`[singing]`** | RMS | +28.8% | **+39.6%** | ✅ |
| | 频谱质心 | +13.1% | +22.2% | ✅ |
| | 时长 | +16.3% | +17.4% | ✅ |
| | 动态范围 | −12.8% | +22.6% | ❌ |
| **`[angry]`** | RMS | −25.1% | **+19.7%** | ❌ **反向** |
| | 频谱质心 | +4.4% | −7.0% | ❌ |
| | 动态范围 | +2.1% | −14.5% | ❌ |
| | 时长 | +12.0% | +12.8% | ✅ |
| **`[calm]`** | RMS | −25.3% | **+30.2%** | ❌ **反向** |
| | 频谱质心 | +0.8% | +1.0% | ≈ 无 |
| | 动态范围 | −7.4% | **−28.0%** | ✅ |
| | 时长 | +10.9% | +11.6% | ✅ |

### 修正后的准确表述

> **跨语言迁移是「按标签分化」的，不是全有全无：**
>
> - ✅ **`[whisper]` 与 `[singing]` 跨语言迁移良好**——四个 / 三个指标方向完全一致，
>   日文下的表现与英文几乎同构（whisper 日文 RMS −57%、质心 +73%，甚至比英文更极端）。
>   → **约战日文可以直接用这两个标签。**
> - ❌ **`[angry]` / `[calm]` 这类情绪类标签在日文下方向相反**——
>   英文 `[angry]` 降能量 25%，日文 `[angry]` 反而**升** 20%；
>   `[calm]` 同样反向（−25% vs +30%）。
>   → **日文下不要指望 `angry` / `calm` / `happy` / `sad` / `excited` 这些情绪词。**
> - 📌 **共同点**：无论中英，**带标签都会让时长增加约 +11%~+17%**
>   （因为标签本身占位置），这部分是**跨语言一致的**，可预期。

### 为什么会出现方向相反（机制推测，非实证）

情绪类标签依赖**语料中该情绪的声学实现**（英语 CREMA-D/RAVDESS 的具体喊法与语调）。
日语语音里表达"愤怒"的音高/能量习惯与英语不同，模型在英语数据上学到的
「愤怒 = 降能量 + 变暗」这套映射套到日语上就会**给出相反的结果**。
而 `[whisper]`（气声耳语）和 `[singing]`（唱腔）是**跨语言生理/音乐上通用**的，
所以迁移得住。

> ⚠️ 以上机制解释是**推测**；**可确证的只有上表的实测方向**。

## 六、这次审计暴露的方法论问题

1. **「未验证」≠「不可用」。** 我把"我没测"直接写成了"别指望"——
   这是**用无知冒充结论**。正确写法是"未验证，建议先测"。

2. **从命名/形态推断语义，容易过度概括。**
   「带 `-en` 后缀 → 是拟声不是情绪」是推断，我写成了"说明"（= 事实）。

3. **"训练语料是 X 语言"推不出"其他语言不行"。**
   必须区分**数据分布**与**迁移能力**，后者只能实测。

4. **客观指标 ≠ 语义正确。** 本报告能证明 `[angry]` 在日文下"方向反了"，
   但要证明"日文听起来不像愤怒"，需要听感评测或情感识别模型——
   本报告**没有**做到那一步，措辞已相应收紧。
