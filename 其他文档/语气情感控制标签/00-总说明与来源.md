# 语气 / 情感控制标签 + 微调版本模型 调研总说明

> 整理日期：2026-10-22
> 范围：OmniVoice（k2-fsa/OmniVoice，本机运行于 `<项目根>`，宿主 Qwen3-0.6B）官方能力 + 社区/竞品现状
> 目的：回答「所有的情绪和语气控制标签有哪些」「微调版本模型现状如何」

## 一句话结论

1. **OmniVoice 没有独立的「情绪 / 语气」维度标签。** 官方可控的「情绪向」信号只有一个来源——**13 个非语言符号**（笑声、叹气、疑问、惊讶、不满等）；语音设计（voice design）属性里**只有 `whisper`（耳语）这一种 style**，其余均为性别/年龄/音高/口音/方言等「说话人属性」，不是情绪。
2. **作者已在 GitHub issue #78 明确：情绪/语气标签需要带标注的数据集，官方目前没有这种数据，原生不支持 `[happy]`/`[sad]` 这类标签。**
3. **但社区已经把这块补上了**，共三种范式（详见《微调新增能力与标签总表.md》）：
   - **行内情绪标签**：`ModelsLab/omnivoice-singing` → `[singing]` + `[happy]`/`[sad]`/`[angry]`/`[nervous]`/`[whisper]`/`[calm]`/`[excited]`（8 个，其中 `calm`/`excited` 弱）；
   - **情绪进 `instruct` 维度**：`issai/KazGenericTTS` → 18 个 NVV 标签 + `emotion{7}` 词条；
   - **词级 5 维韵律向量**：`multimodalart/omnivoice-word-control` → 116 个 `<|dur_*|>`/`<|bnd_*|>`/`<|eng_*|>`/`<|pit_*|>`/`<|ton_*|>` 控制 token。
   另有 `amanuelbyte/omnivoice-lora-zh|fr|ar` 属**语言克隆增强**（无新标签），`Dezheen89/omnivoice-badini`、`NMikka/omnivoice-finetuned-ka` 亦为语言增强类、**不涉及情绪**。
4. **⚠️ 所有情绪 / 韵律微调的训练语料都是英文或哈萨克语**——对约战素材的**日文情绪完全未验证**，日文演出仍应走「角色克隆 + 13 非语言符号 + 情绪参考音频拼接」。
5. **本机 RTX 3080 10GB / 15.9GB 内存无法训练**（全参需 8 卡或 A100/H100 级，LoRA 也建议 ≥24GB 显存）；只能推理 + 加载已发布权重。

## 重要提示（本机视角）
- 本机可直接**使用**全部 13 个非语言符号、语音设计属性、拼音/CMU 发音纠正（经 `server.py` 的生成端点或 `omnivoice` CLI）。
- 本机**无法训练/微调**（见 `微调版本模型调研.md` 第五节硬件结论）。
- 语音设计仅在**中文、英文**数据上训练（官方 README 明确），对约战素材用的**日文**可泛化但可能不稳定——这也是约战测试文本建议走「克隆」而非「语音设计」的原因。
